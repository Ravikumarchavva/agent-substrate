# Screenshots

Drop the images referenced by the top-level `README.md` here. Filenames matter —
keep them exactly as below so the README renders:

| File | What to capture |
|---|---|
| `hero.png` | The main chat view with the artifact panel open on the right (e.g. a generated report/spreadsheet). This is the banner shot. |
| `onlyoffice-edit.png` | An Office file (pptx/xlsx/docx) open in the ONLYOFFICE editor inside the panel, ideally in Edit mode. |
| `version-history.png` | The version-history dropdown open, showing the initial / You / Assistant lineage. |
| `code-monaco.png` | A code/text file open in the Monaco editor with the Save control visible. |

Tips:
- Use a wide window (≥ 1440px) so the chat + panel both show.
- PNG, trimmed to the app (no OS chrome) looks cleanest.
- Keep each under ~1 MB; downscale to ~1600px wide if needed.
